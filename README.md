# PC Diagnostics

USB-SSD-levyltä käynnistettävä tietokoneiden
diagnostiikkajärjestelmä.

## Teknologiat

- Python 3
- Flask
- SQLite
- Debian 13
- HTML, CSS ja JavaScript

## Ominaisuudet

- Laitteistotietojen kerääminen
- Diagnostiikkatestien suorittaminen
- Testitulosten tallennus
- Tulosten analysointi
- PDF-raportointi

## Kehitysympäristö

Windows 11 ja Visual Studio Code
